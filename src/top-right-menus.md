# Top-right Corner (File and View)

The top-right corner contains from left to right the file menu, the
audio menu, the zoom menu, the rotation menu and the view menu

### File Menu

The default option is "Save game".

* Load Game - Discard current game and select a save to load

* Save Game - Save the current game to a new or existing file

* About 'Chris Sawyer's Locomotion' - Open a window to view information
about the game

* Options - Open the [options window](options-window.md)

* Screenshot - Save a screenshot to disk

* Giant screenshot - Save an image of the entire map to disk

* Quit to menu - Return to the [title-screen](title-screen.md)

* Exit OpenLoco - Close OpenLoco and return to desktop.

> [!NOTE]
>
> Screenshots are saved in the `screenshots` directory (folder) in
> OpenLoco's data directory. See [Accessing Assets, Saves and
> Screenshots](openloco-directories.md) for more details.

> [!NOTE]
>
> The game may prompt you if you wish to save before you load a save,
> exit to menu or exit OpenLoco and you have not manually saved in a
> while. Do not rely on this as you may not be prompted.

### Audio Menu

The default option is "Mute".

* Mute - Toggle sound

* Play Music - Toggle music

* Music Options - Opens the options window and select the audio options tab

### Zoom Menu

The default option is normally to "Zoom In". However, if the main
viewport is fully zoomed in, the default option is to "Zoom Out". This
default remains until the main viewport is fully zoomed out or the
cursor moves off the zoom and map menu.

* Zoom In - Increase the scale of the main viewport; one can see less of
the world, but can see it in more detail

* Zoom out - Decrease the scale of the main viewport

* Map - Open the [map window](map-window.md)

> [!TIP]
>
> You can also use the scroll wheel to zoom in and out. The area under
> the cursor will remain the same part of the screen, so this can be
> used to focus on an area or entity of interest.

### Rotate Menu

The default option is to "Rotate Clockwise".

* Rotate Clockwise - Rotate from facing North to East, East to South,
South to West and West to North.

* Rotate Anti-Clockwise - Rotate from facing North to West, West to
South, South to East and East to North.

> [!TIP]
>
> You can also rotate the viewport by using the scroll wheel while
> holding the right mouse button.

### View Menu

The default option is the toggle the "Underground view".

* Underground view - Toggle between the normal view and a wireframe view
of the ground

* See-through tracks - Toggle between opqaue and see-through railway and tram tracks

* See-through roads - Ditto for roads

* See-through trees - Ditto for trees and cacti

* See-through buildings - Ditto for town buildings and industries

* See-through scenery - Ditto for fences and walls

* See-through bridges - Ditto for bridge supports and decks

* Height marks on land - Toggle markers showing the median height of each land
tile, rounded down to the tile (5 m or 16 ft)

* Height marks on tracks and roads - Toggle markers showing the height
of each tile of track, including construction ghosts, rounded to the
nearest tile

* Town names displayed - Toggle the visibility of town names

* Station names displayed - Ditto for station names

> [!NOTE]
>
> The underground view is automatically toggled when constructing
> underground infrastructure. Vehicle windows will use the underground
> view when the vehicle is shows is underground.

> [!NOTE]
>
> See-through objects will slightly visible unless the underground view
> is on.
