# Building and Modifying Vehicles

Vehicles can be built by either building a new vehicle from the build
vehicles menu or by cloning an existing vehicle. Once a vehicle is built,
it can be modified using the second tab from the left of its window.

## Building New Vehicles

Building a new vehicle starts in the build vehicles menu, on the right of 
the construction menu group. Each entry in the menu will open the build 
vehicles window and select the appropriate tab. The menu will default to 
selecting the last mode of vehicle selected. If no vehicles have been 
built since the last load, then the menu defaults to the top-most 
available mode.

The build vehicles window has a tab for each mode of transport (trains, 
busses, trucks, aircraft, trams and ships). The left hand side has tabs 
for subtypes of vehicles. These subtabs each have a list of components. 
Above the list is a searchbox and a pair of dropdowns. The left 
drop-down allows one to sort by design year or by name and to filter 
powered or unpowered components. The right drop-down filters components 
by the cargoes that they carry.

The right hand side shows a preview of the selected component, its name, 
a list of cargoes that it carries and then lists the component's 
statistics. To see a different component's statistics, hover over it. 
Click on an appropriate component while no vehicles have their vehicle 
details window open to create a new vehicle with that component.

## Modifying A Vehicle

Vehicles are modified from the vehicle details tab (the second tab from 
the left of its window, with a spanner icon) and the build vehicles 
window. Vehicles can only be modified while they are stopped.

The left part of the tab shows a list of the vehicle's components, from 
start to end. Components can be dragged around the list to re-order 
them. However, trains will always have a locomotive or driving carriage 
at the front. If two vehicles' windows are open, components can be 
dragged between them.

Components can be sold by dragging them to the rubbish bin on the right 
of the window. The whole vehicle can be sold by clicking the that bin.

Components can also be repainted. Click the painbrush on the bottom of 
the right-hand toolbar. Two colours - the primary and second colours - 
will be shown and can be changed by clicking on them. Click on a 
component to change it to the colour scheme shown. One can also repaint 
the whole vehicle by clicking-and-dragging from the paintbrush icon to
the menu option 'paint all connected'.

The topmost icon in the right toolbar, which has a crane, opens the 
build vehicles window. Components can be added to vehicles. When a 
component is bought from the build vehicles window, it will be added to 
the last-used window that is on the vehicle details tab. Only components 
compatible with this vehicle can be bought.

> [!NOTE]
>
> There is no indication for which vehicle components will be added to. 
> To avoid confusion, click the window for the vehicle to extend before 
> buying components and close the vehicle's window when done.

Buses, trans, aircraft, ships and most truck can only have one 
component. Select trucks can have a trailer added to them. Most 
locomotives can pull any ordinary carriage and any carriage can be 
pulled by most locomotives. However, some power cars can only be used 
with special carriages. Multiple units can generally only be used with 
other multiple units of the same model.

## Cloning A Vehicle

Vehicles can also be cloned from the vehicle details tab. To do so, 
click-and-drag from the crane icon on the top of the toolbar on the 
right to the 'clone vehicle' option that appears.

The new vehicle will have the same components, colour scheme and orders 
as the original vehicle. However, the two vehicles are independent: 
changing one vehicle's components, colours or orders will **not** change 
those of the other vehicle.
