# Menus

The menus are the starting point for most actions. To use a menu, hover
over it, carefully move the cursor over your selected option and click
it.

> [!IMPORTANT]
>
> A default choice will be picked if you click the menu. The following
> sections will document the default choice for each menu.

Each corner of the screen contains a set of menus. Generally speaking:

* The [top-right corner](top-right-menus.md) is used for file mangement and adjusting the view

* The [top-left corner](top-left-menus.md) is used to build infrastructure and vehicles and to view information.

* The [bottom-right corner](bottom-right-menus.md) is used to assess company status

* The [bottom-left corner](bottom-left-menus.md) is used to control time and view the map
